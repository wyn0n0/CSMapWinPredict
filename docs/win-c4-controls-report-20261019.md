# C4 状态与连续距离固定对照结果

2026-10-19，完成[预先冻结的 A／B／C 对照](plans/win-c4-controls-20261019.md)、真实训练和独立复核。

**1vN 的主要改善在状态组 B 中已经出现；真实 C4 距离对广义残局有额外改善线索，但整体增量区间仍跨零。按预先规则，全回合路线后续优先验证 B，保留 C 作为广义残局候选。生产和独立残局默认模型均未切换。**

## 范围与比较方式

- 只使用原 79 场训练比赛：1,727 回合、151,402 点。旧 8 场验证和已观察 13 场开发比赛均未用于拟合、校准或评分，没有新最终测试。
- A 为广义残局定义下的基础模型；B 加入质量／人数、C4 状态和缺失信息，将六个 C4 连续字段的非空值置零；C 与 B 保留完全相同的状态和缺失模式，使用真实距离。其余已有空间聚合不变。
- 原始输入字段数 A 为 97，B／C 为 114；三者内部计算广义残局标志。全训练模型编码后分别为 146／172／172 列。B 仍需原始 114 字段确定缺失模式，本轮没有减少采集字段的部署改造。
- 固定逻辑回归 C=1、seed 42、4 线程、Sigmoid 校准、原定时采样及回合权重。三个候选均用完整回合训练，残局是评估切片。
- 外层 5 折按完整比赛隔离；每个外层训练部分再做 5 折，校准器只读取该训练部分的折外预测。预处理、模型和校准均不读取外层保留比赛。共拟合 108 次基础模型，保存 15 个外层包及 3 个全训练包；下列分数全部来自外层保留比赛。

这是一轮训练内开发验证，不能称为新盲测，也不能把这里的分数直接与旧 13 场开发集分数比较后宣称提升。

Log Loss 衡量概率预测误差，越低越好。三个候选的预测覆盖率均为 100%。

## 配对差值及解释

以下为候选减参照的 Log Loss 差值；负值有利于候选。区间按整场比赛重采样 2,000 次，seed 42，95% percentile。

| 对照／场景 | 差值 | 95% 区间 |
| --- | ---: | --- |
| B−A：整体 | −0.001154 | [−0.002238, −0.000070] |
| B−A：广义残局 | −0.002788 | [−0.005664, +0.000234] |
| B−A：1vN | −0.010803 | [−0.017221, −0.003923] |
| C−B：整体（主要距离对照） | −0.000637 | [−0.001514, +0.000195] |
| C−B：广义残局 | −0.001543 | [−0.003071, −0.000163] |
| C−B：1vN | −0.000439 | [−0.002103, +0.001173] |
| C−B：下包后 | −0.001006 | [−0.002847, +0.000702] |
| C−A：整体 | −0.001791 | [−0.003169, −0.000458] |
| C−A：广义残局 | −0.004331 | [−0.007441, −0.001383] |

由此得到三个有限结论：

1. **1vN 的改善不能主要归因于连续距离。** B 已获得大部分点估计改善，C 相对 B 的 1vN 区间仍跨零。A 已移除旧 `isClutch`，B 的缺失模式又包含“某方仅剩一人”等更细状态；状态组还包括冗余计数和炸弹状态，不能进一步把全部收益归给某一个标记。
2. **连续 C4 距离在广义残局中有独立于上述缺失模式的增量线索。** C−B 的广义残局 Log Loss 区间低于零；但对应 Brier 区间 [−0.000919, +0.000035] 仍跨零。不能概括成距离完全无用，也不能宣称所有残局指标都稳定改善。
3. **全回合路线按冻结规则优先验证 B。** C 的整体点估计更低，但 C−B 主指标区间上界为正，没有达到预先要求；开局及 5v5 的点估计也略差于 B。保留 C 供广义残局路线的新比赛验证，不因本轮结果再追加候选或改参数。

逐比赛诊断中，B−A 的整体／1vN 分别有 47／56 场改善；C−B 的整体／广义残局／1vN 分别有 50／47／39 场改善。去掉任意一场后，C−B 的整体平均差值仍在 [−0.000743, −0.000510]，广义残局在 [−0.001796, −0.001284]。这说明点估计不是单场独自支撑，但不会让跨零区间自动变成确定提升。

这些区间条件于本批固定折外预测，外折模型共享训练数据，重采样没有重新训练模型；多场景未做多重比较校正。它们不覆盖全部训练不确定性，也不构成新比赛的最终采用证据。旧来源登记、新测试名单、采用容忍度和实际端到端预算仍按 M2 补齐。
