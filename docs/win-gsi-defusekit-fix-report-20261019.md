# GSI 拆弹器字段省略修复与同场复验

## 修复范围

`endgame_prediction/gsi/adapter.py` 的共享装备解析函数现在将**键不存在**的 `state.defusekit` 解释为 false，适用于完整观战快照中的 T／CT。此前 CT 的省略值被视为未知，进而使双方整组装备统计置空。

显式 true／false 仍按原值处理；显式 null、数字、字符串或其他非法类型继续作为未知，包括 T 方的显式 null。名单不完整、生命状态未知仍拒绝预测；现金、护甲、头盔、装备价值、武器或道具数量真正缺失时，继续保留原装备置空保护。原始对象不补写字段，不沿用上一快照的拆弹器状态。

契约、114 个输入字段、模型权重、概率校准器及生产默认模型均未改变。此次仅修改 GSI 适配器和相关测试；已运行的服务不会热更新，下一次手动启动／重启本地 `server.py` 或 `record.py` 时加载新代码。本次没有终止或重启用户进程。
