# M4 空间特征拆组开发报告

> 2026-10-15。完成预先固定的 22 个候选、22 个配对比较和独立复算。沿用 79 场训练、13 场已观察开发数据，旧 8 场不进入本轮训练或选择。默认模型保持不变。

**结论：优先保留“原特征＋质量组＋C4 组”的逻辑回归作为后续验证候选，队友间距组作为较小的备选。** 两组单独加入时改善了本批开发比赛的整体和 1vN 指标；但从完整模型中移除任一组，变化都很小，不能把它们的收益相加，也不能认定 C4 是唯一来源。携包人接应和包点附近人数没有显示明确的独立残局收益。

这仍是同一批已观察比赛上的探索，且各组包含人数、适用性或缺失标记。**本轮验证了语义组的表现，尚未证明收益来自纯几何数值。** 不据此切换生产模型。固定设计见[拆组方案](plans/win-spatial-ablation-20261015.md)，上一轮结果保留在[M4 报告](win-m4-development-report-20261015.md)。

## 3. 拆组取舍依据

以下为逻辑回归的配对 Log Loss 差值及 95% 区间。2,000 次整场重采样，所有比较使用相同样本与权重。加入差值为负表示改善；移除差值为正表示删掉后退化。未作多重比较校正，不作为独立泛化认证。

据此保留如下开发结论：

1. **C4 组优先继续验证。** 115 字段逻辑回归在本轮 1vN 点估计最佳，整体、下包后和 1vN 均优于原默认；比完整空间模型少 13 字段。它不是整体排名第一的算法，也不是唯一有收益的空间组。
2. **队友间距组保留为简化备选。** 109 字段逻辑回归有相近的残局改善线索。移除它对完整逻辑回归影响很小，说明其新增价值依赖已有输入，不能要求所有模型同时采用 C4 和队友间距。
3. **携包人接应、包点人数不作为下一轮逻辑回归的必选输入。** 单组加入与整体移除的区间大多跨零，没有足够证据要求增加字段。没有据此删除原空间导出或旧实验模型。
4. **LightGBM 单独判断。** 仅加 C4 相对 Q 对照的整体差值为 −0.002695，区间 [−0.005350, −0.000008]，但残局差值接近零。移除队友间距反而使整体变差：+0.002454，[+0.000698, +0.004151]。树模型移除携包人或包点人数时，残局指标改善但整体区间仍跨零，体现了组合及场景依赖，不能照搬逻辑回归取舍。

本轮整体开发排名第一是 115 字段的 C4 LightGBM：Log Loss 0.476535。相对当前默认差值 −0.007058，区间 [−0.017646, +0.003607]；开局和 5v5 的 ECE 分别为 0.07295、0.07413，高于默认的 0.05955、0.06252。因此不因排名第一就推荐直接替换。

## 5. 不能把全部收益归因于距离数值

全量可用性检查发现：175,891 点的炸弹位置都已知，双方位置与阵容状态都完整；双方有效位置人数、有效 C4 距离人数均等于观测存活人数。开发集的观测存活人数还与原模型存活人数逐点一致。Q 的冗余计数仍可能影响正则化或树的拟合，不能把 Q 当作纯粹的缺失信息增量。

更关键的是，C4 次近距离和队友间距在不足两名队员时同时为空。开发集 T 侧各有 1,828 点为空，CT 侧各有 1,956 点为空，源代码中的成立条件一致。现有预处理会生成缺失指示列，这些列包含人数／不适用信号。因此 C4 与队友间距的相似收益，**可能部分来自共享的状态信号**；本轮未分离这部分与连续距离值的贡献。

下一步若继续精简，应另行固定“仅人数／适用性／缺失标记”与“加入连续几何值”的小对照，优先在训练内分组验证，不在本轮 22 候选结果后追加组合搜索。正式采用仍需补齐来源登记、预定场景退化容忍度和预算，冻结一个候选并使用新的未观察比赛。现有 13 场不能再称为盲测。

## 6. 工程验收与工件

- 新入口 `freeze --suite spatial-ablation` 复用现有训练、校准、评估和推理。默认 `--suite m4` 保留原 20 候选。所有空间子集都绑定配置哈希，原生产入口继续拒绝实验模型。
- 本轮通过 **42 项 Python 检查**：7 项实验检查、28 项原 v4 训练／冻结、7 项原推理。覆盖分组完整互斥、严格增删、对照选择、未选字段不影响预测、错误契约／配置拒绝与旧候选不变。未改 C#、解析或 UI，未重跑无关 .NET／前端构建。
- 22 个包独立加载，对全部开发点完成 **538,758 次预测**，与各自训练模型输出最大差为 0。分折与上一轮完全相同，训练和校准没有开发／旧验证比赛参与。
- 独立核对 **163 个新结果工件**、上一轮 **149 个结果工件**及冻结输入／源码哈希；690 项整体／场景 Log Loss、Brier 复算误差为 0，220 项配对点估计最大误差为 2.88×10⁻¹⁶。
- E0/E3 的两种算法预测与上一轮对应结果完全相同；重训 E0 与更早的默认包仍有最大 1.05×10⁻⁸ 的数值差，保持数值复现口径，不声称模型文件逐字节一致。
- 累计拟合约 **701.7 秒**，训练／评估报告计时约 **1,004.9 秒**（不含前置加载／审计及最后写出）；从 started 到 completion 约 **19.1 分钟**，符合开跑前 10–20 分钟预算。256 点批次中，原逻辑回归、C4 逻辑回归、完整空间逻辑回归约为 0.198／0.207／0.227 毫秒每点，仅为本次成本记录，不作为在线性能承诺。
