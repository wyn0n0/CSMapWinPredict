# 广义残局模型重训报告

2026-10-15，按[冻结方案](plans/win-broad-endgame-retrain-20261015.md)完成四个逻辑回归模型、四项配对比较和独立复核。新模型已实际训练并通过独立推理；本轮开发第一名为 `B_c4_logistic`，生产默认保持不变。

**新定义在基础版和 C4 版上都小幅降低了整体及广义残局误差，但对应 95% 区间均跨零，不能据此认定稳定提升。** C4 新版的 1vN 指标较旧 C4 版微幅退步，不能宣称所有场景都改善。13 场开发比赛此前已被观察，结果不属于新盲测。

## 训练与模型含义

- 广义残局为 live/post-plant、双方各 1–5 名已知整数存活人数、合计 ≤ 7。训练、推理、评估共用同一判定；阶段结束、0vN、未知或非法人数不计入。
- `B0` 和 `B_c4` 移除旧 `features.baseline.isClutch`，由模型管线内部计算 `derived.isBroadEndgame`，契约为 `win-broad-endgame-v1`。输入字段分别为 97／114，加入派生字段后模型字段为 98／115。没有改写旧导出或让旧权重接收新含义。
- 79 场训练：1,727 回合、151,402 点；13 场开发：271 回合、24,489 点；旧 8 场与最终测试不参与本轮。复用并重新审计全部 175,891 点的空间伴随数据。
- 5 折整场分组、seed 42、4 CPU 线程、C=1、固定 sigmoid 校准及原回合权重。校准只拟合训练内 OOF，未加权强化残局或新增参数搜索。
- 广义残局开发覆盖 13 场、263 回合、8,361 点，原权重合计 90.895047；1vN 为 3,104 点，下包后为 3,754 点。所有模型输出覆盖率均为 100%。

逐场诊断中，新 C4 相比旧 C4 的广义残局为 8 场改善、5 场退步；逐次留掉一场后的总体广义残局差值为 −0.001818 至 −0.000699。1vN 为 4 场改善、9 场退步。开局 Log Loss 为 0.618397，高于当前默认的 0.616926；5v5 为 0.622751，默认为 0.622865。完整逐场、覆盖率、校准分桶及其他分组保存在 JSON 报告。
