2026-10-19。使用同一场 Mirage 的完整 GSI 录制及配套 Demo，对照固定的 2026-10-17 仅残局模型。**主要偏差来自 GSI 装备字段的缺失处理；本场数据尚不支持把 GSI 输入视为与 Demo 输入等价。** 未重训、修改线上适配器或切换模型。

## 配对与评价口径

从头按原接收顺序回放 GSI 适配器，以保存的接收时间判断时效。1,754 条重算胜率与录制结果最大差 `4.44e-16`，仅浮点计算精度差。胜负标签保存在分析元数据中，不传入模型。

Demo 沿用已有 64 tick 导出步长。每个残局点在同回合、同阶段中选择倒计时最近的 GSI 快照，门槛为 0.55 秒，每条 GSI 最多使用一次；匹配不读取胜方或概率。768 个 Demo 点中获得 765 对，排除 3 个重复锚点。再要求存活玩家身份及阵营、团队总血量、炸弹状态一致，得到 **739 对、24 回合**，占 Demo 残局点的 96.22%。

严格配对倒计时差中位 0.109 秒、P95 0.247 秒、最大 0.347 秒，并非精确同 tick。每对局面的最大玩家 XY 位移差中位 20.91 世界单位、P95 54.89。进一步限制全部玩家位移差 ≤64 单位后保留 728 对，平均概率差仍为 12.03 个百分点，主要结论不依赖较大位置差的少数点。

主要效果指标采用**每个回合等权、回合内配对点等权**，避免长回合支配结果。概率差均值、分位数和翻转计数为逐配对点统计。准确率指概率 ≥50% 所选胜方与真实回合胜方一致的比例；Log Loss、Brier 和 ECE 越低越好，后者衡量预测概率与实际结果的偏差。

## 偏差来源与离线诊断

本次客户端对存活 CT 的 `state.defusekit` 只出现 `true` 或省略，从未出现显式 `false`。现有 `equipment()` 将 CT 省略字段解释为未知；任一存活者装备未知都会使双方整组装备统计置空。

- 1,754 个 GSI 预测点中，1,585 个（90.36%）触发装备缺失，**原始缺失原因全部只有 CT 拆弹器字段**。现金、护甲、装备价值和武器信息虽存在，仍随整组被屏蔽。
- 739 个严格配对点中，668 个 GSI 装备价值为空，同点 Demo 为 0 个。实际 52,768 条训练样本的双方装备价值也从未缺失，质量类别全部为 `usable`，形成明显的训练／应用输入分布差异。
- 739 对中，将 GSI 显式 `defusekit: true` 的存活 CT 数量与 Demo 拆弹器人数比较，**739/739 一致**，为本次完整快照中“省略表示没有”提供同场证据。

仅在内存副本补入该 false 值，其他特征与模型不变，严格配对点的装备缺失全部消失；平均概率差由 12.07 降至 1.72 个百分点，减少约 85.7%。另一项诊断直接将配对 Demo 的装备组替换进 GSI，平均差同为 1.72 个百分点、Log Loss 为 0.266238，得到相近结果。这种替换只用于解释来源，不是可部署输入流程。

其他差异仍存在：GSI 没有 Demo 的精确阶段累计时间、炸弹状态变化次数、上次变化时间、区域与部分历史；位置和倒计时也存在采样差。单独替换时钟组，平均概率差为 12.22 个百分点；单独替换炸弹历史／区域组为 10.49 个百分点。装备处理是本场主要可定位原因，不代表其余字段已全部等价。

**离线省略值解释尚未写入适配器。** 739 对验证支持本次客户端与完整快照，不能普遍把未知字段变为 false，也不能将一场数据上的诊断效果作为新版本最终盲测成绩。

## 与既有 Demo 测试成绩的关系

既有 13 场、263 回合、8,361 点结果已从保存预测复算：准确率 **86.29%**、Log Loss **0.299243**、Brier **0.093179**，与原报告一致，使用原完整回合样本权重，筛选残局后不重新归一化。

本次同场 Demo 全部 768 个残局点按相同原权重口径得到准确率 **85.53%**、Log Loss **0.278780**、Brier **0.089070**。主表使用配对后的回合等权，因此其中 86.95% 不应直接作为原 86.29% 的增量。这是单场固定模型诊断，不能证明泛化能力提升或下降。

GSI 全部 1,754 点逐点平均准确率为 83.07%，每回合等权为 84.32%。同回合密集采样不构成独立比赛；只有一场比赛，不计算声称能代表新比赛总体表现的置信区间。
