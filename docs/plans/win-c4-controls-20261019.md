# C4 状态与连续距离固定对照

2026-10-19。用户批准执行此前讨论的 A／B／C 对照。本方案在训练前固定，只使用原 79 场训练比赛；旧 8 场和已观察 13 场均排除，不评估新盲测、不切换生产或独立残局默认模型。

## 固定问题与候选

检验 C4 语义组的收益有多少来自状态、人数和缺失标记，以及保留这些信息后，连续 C4 距离是否仍提供增量。基础特征本身已含旧空间聚合，因此这里的“距离”仅指新增的六个 C4 连续字段，不能解释为所有空间信息。

| 候选 | 原始输入 | 处理 |
| --- | ---: | --- |
| A_base | 97 | 原 B0：旧 98 字段移除 isClutch，内部计算广义残局标志 |
| B_state | 114 | 原 B_c4：基础＋质量／人数＋C4 组；六个 C4 连续字段的非空值全部置零，空值保持 |
| C_distance | 114 | 与 B 完全相同的原始字段及缺失模式，保留真实 C4 距离 |

六个字段为 T／CT 的最近、次近 C4 距离，以及对应两种距离的双方差值。B 保留距离有效人数、炸弹状态、位置状态、质量／人数，以及与 C 完全相同的缺失指示列；零常量列经标准化后不提供连续信息。没有额外复制指示列，以免改变正则化中的重复信号。B 的原始接口仍需 114 字段来确定缺失模式，不将其误称为减少采集字段的模型。

三个候选均按完整回合训练，广义残局只作派生特征和评估切片；不是再次只用残局样本重训。B−A 衡量整组状态信息增量；C−B 是主要对照，衡量条件于相同状态／缺失模式的连续 C4 值；C−A 为总体对照。拟合系数会重新调整，差值不是因果贡献，也不机械相加。

## 数据与评估

- 原 79 场、151,402 点、1,727 回合，原每秒采样和回合权重保持不变，切片后不重新归一化。只读复用匹配这些比赛的 79 个空间伴随分片；重新核对原始证据、基础行、来源哈希和一对一键。
- 固定逻辑回归 C=1、seed 42、4 CPU 线程、Sigmoid 校准，不做参数搜索或校准方案选择。
- 外层固定按整场比赛分组的 5 折。每个外层训练部分重新进行 5 折分组拟合，产生供 Sigmoid 拟合的训练内折外预测；外层保留比赛完全不参与预处理、模型或校准。A／B／C 共用相同的内外层成员。
- 主指标为全部外层折外预测的加权 Log Loss；同时报告 Brier、ECE、AUC、准确率、预测覆盖率、逐场指标及整体／开局／5v5／下包后／广义残局／1vN 切片。
- 配对区间为 seed 42、2,000 次整场重采样、95% percentile。它条件于本批固定 OOF 预测；外折模型共享训练数据，重采样不重新训练，不将区间描述为新比赛认证或所有训练不确定性。
- 若 C−B 整体 Log Loss 区间上界未低于零，后续优先较简单的 B 表示；若低于零，再结合关键场景检查是否值得保留距离。此规则只确定后续验证方向，不构成生产采用门槛。对 A 的差值和场景退化必须同时披露。
