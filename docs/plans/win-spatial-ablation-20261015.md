# M4 空间特征拆组开发验证

> 2026-10-15。用户要求推进空间特征拆组验证，沿用已批准的原 79 场训练、已观察 13 场开发、旧 8 场仅作诊断的范围。本方案在本轮训练前固定，不切换默认模型，不产生最终采用资格。

## 问题与固定分组

上一轮 [M4 开发对照](../win-m4-development-report-20261015.md)发现，加入全部 30 个 M3 字段的逻辑回归在 1vN 有改善线索。本轮检验收益来自哪些字段组，以及单组收益与组合收益是否一致。它是同一开发集上的后续探索，不是新的独立验证。

30 个字段划为互不重叠、完全覆盖的五组。精确字段清单随冻结计划和源码保存：

| 组 | 字段数 | 内容 |
| --- | ---: | --- |
| Q：观测质量／人数 | 7 | 双方观测存活人数、有效位置人数、位置状态及阵容完整状态 |
| C：实际 C4 | 10 | 双方有效 C4 距离人数、最近／次近 C4 距离、双方距离差、炸弹状态与位置状态 |
| B：携包人接应 | 5 | 队友人数、有效队友位置人数、最近队友距离、支援半径内队友数、携包状态 |
| S：包点附近人数 | 4 | 双方在 A/B 包点半径内的人数 |
| F：队友间距 | 4 | 双方每位玩家最近队友距离的平均值和最大值 |

Q 包含与已有存活人数相关的冗余计数，不能将 Q 的收益一概解释为缺失处理。C、B 保留各自适用性与有效人数字段；本轮比较的是完整语义组，不能将收益全部归因于距离数值。

## 22 个固定候选

每项运行逻辑回归和 LightGBM；沿用原参数（逻辑回归 C=1；LightGBM 15 叶、深度 5），不调参、不加交互。不是上一轮开发排名第一的 31 叶设置。

| 标识 | 字段数 | 定义 |
| --- | ---: | --- |
| E0 | 98 | 原模型字段，重训并与既有包核对 |
| E3 | 128 | E0＋全部 M3 字段，复现上一轮完整空间对照 |
| S_quality | 105 | E0＋Q，区分观测计数／质量与几何组 |
| S_only_c4 / carrier / site / formation | 115 / 110 / 109 / 109 | E0＋Q＋指定一组 |
| S_without_c4 / carrier / site / formation | 118 / 123 / 124 / 124 | E3 移除指定一组，仍保留 Q |

每种算法固定 11 个配对比较：Q 对 E0、E3 对 E0、E3 对 Q、四个单组加入对 Q、四个移除对 E3。加入差值为负表示改善；移除差值为正表示移除后退化。组合中训练系数和分裂会重新拟合，不能将各组差值相加或视作因果贡献。若一组单独加入与移除表现不一致，报告为依赖组合或证据不足，不继续现场搜索组合。

## 数据、评估与成本

- 只读复用 `.artifacts/win-m4-20261015-r1/` 中已导出的 92 场空间伴随数据；无需重解析 Demo。重查清单、原始证据与全部基础行，任一错配失败。半径继续为支援 861.320、包点 582.716 世界单位。
- 原采样、回合等权重、seed 42、相同按比赛分组的 5 折、4 线程、Sigmoid 校准不变。校准仅使用训练内 OOF；其他校准方法仍只报告训练内诊断。
- 主指标为整体加权 Log Loss；重点复核 1vN，同时报告开局、5v5、下包后、Brier、ECE、覆盖率和逐比赛结果。每个配对比较使用 2,000 次整场重采样和 95% 区间。多候选、多场景未作多重比较校正，结论限于探索线索。
- 全部新模型、预测、冻结源码和报告写入不存在的新目录 `.artifacts/win-spatial-ablation-20261015-r1/`。输入、特征、对照、依赖、成员和源码在训练前绑定哈希；旧模型、旧报告和旧冻结不回写。
- 预计审计加 22 候选训练／评估约 10–20 分钟，新增工件控制在 1 GiB 内；不重复全量导出，不改变默认模型或 API 配置。预估只是执行预算，实际成本在结果中记录。

## 实现与验收

复用 `tools/train_win_experiments.py`，只新增 `freeze --suite spatial-ablation`。默认 `--suite m4` 仍产生原 20 候选；新空间子集继续使用 `win-m4-v1` 实验契约，所有使用空间字段的模型都绑定配置哈希。生产入口继续拒绝实验包。

```powershell
python -B tools/train_win_experiments.py freeze --suite spatial-ablation --legacy-dir <legacy-v4-directory> --development-dir <observed-development-directory> --development-registry <M2-registry.json> --validation-split <original-79-8-split.json> --baseline-dir <existing-model> --spatial-root <existing-M4-export-root> --observed-development --output-dir <new-freeze-directory>
python -B tools/train_win_experiments.py run --plan <new-plan.json> --plan-sha256 <frozen-sha256> --output-dir <new-results-directory>
npm run test:train:m4
```

定向测试覆盖互斥分组、严格增删、对照选择、未选字段不影响预测、空间配置错误拒绝，以及旧 M4 20 候选不变。每个新包独立加载后对所有开发点核对训练／推理输出；最后从保存的预测独立复算指标、核对旧 E0/E3 的数值复现、检查折内比赛隔离和全部结果哈希。旧 M4 冻结绑定旧源码，重放它须使用原快照，不能重写旧哈希来适应新代码。
